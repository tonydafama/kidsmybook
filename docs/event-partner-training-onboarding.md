# RECF Event Partner（EP）訓練與認證 — 內部指引

呢份文件整理官方入門資源同認證路徑，方便同事跟住做。內容唔包括任何考試題目；準備同應考請跟足 RECF／training 平台規則。

1. [RECF Event Partners 總覽](https://recf.org/event-partners/)

4. [Event Partner Training & Certification Course（說明文章）](https://kb.roboticseducation.org/hc/en-us/articles/5458612573207-Event-Partner-Training-Certification-Course)

## 2) 想盡快考認證時嘅建議步驟

1. 喺 [robotevents.com](https://www.robotevents.com/) 註冊**免費**帳號。  
   - 一般建議用**工作電郵**；若預期短期內會轉工但仍想長遠擔任 EP，可以改用**個人電郵**（自行權衡與機構紀錄一致嘅需要）。
2. 喺 [training.recf.org](https://training.recf.org/) 再註冊**免費**帳號。  
   - **電郵必須同 robotevents.com 帳號一致**。
3. 登入 `training.recf.org` 後，揀 **「VEX V5 Robotics Competition」**。
4. 再揀 **「VEX V5 Robotics Competition Event Partner Training and Certification」**。
5. 開始課程；課程會連去 RECF Library — Event Partners 入面多數相關連結。
6. 官方估算閱讀／學習約 **9 小時**（實際因人而異）。
7. 最後一節係認證考試；**合格分數為 95%**。
8. 考獲證書後，將證書交畀負責同事，以便**內部紀錄／存檔**。
9. 每張 Event Partner 證書**有效期 2 年**；即大約**每第三年需要續期**（以 RECF 當時政策為準）。
