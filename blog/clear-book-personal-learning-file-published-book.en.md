Parents who search for a secondary Clear Book, or for a personal learning portfolio, often finish the thought with “clip the school reports, certificates, and self-introduction together, then photocopy the whole book into the clear file”. This page does not start from the file. The Kidsmybook lead is publishing plus a physical bookstore listing: the child takes part, an about-12-month mentored programme prints the book, and the title and package then follow a supply path toward bookstore platforms such as Joint Publishing, Commercial Press, or Chung Hwa. A secondary portfolio, a Clear Book, and a personal learning portfolio can cite that result. It is a second use. It is not the first sentence of the plan, and it is not a school place.

In this page, a Clear Book is the clear display file families carry to a secondary, direct-subsidy, or DSS interview and turn page by page. A personal learning portfolio is the same kind of file, used by the school or the family for school reports, certificates, and a self-introduction. The name, whether the file is accepted, the page count, and whether a physical object may be carried in, follow that school’s latest guidelines. The publishing path comes first. How to place one formal publication at the front of that file comes after.

## How does publishing plus a bookstore listing relate to a secondary Clear Book?

The book is a finished publication first. The Clear Book and the personal learning portfolio only decide how to cite it. The path does not end when a book number is issued. The front of it is an about-12-month mentored programme: a consultation, mentor-led making, a university professor review when it fits, parent-and-child layout, and only then a formal print run. Listing is discussed after the book is printed. Listing is a distributor supply path. Once the title reaches platforms such as Joint Publishing, Commercial Press, or Chung Hwa, the store buyer and the store manager decide whether to take it in, where to place it, how long it stays, and whether to return it. Kidsmybook is not those bookstores. Listing depends on the title and package. A title does not appear in every branch by itself. ## A personal learning portfolio usually needs school reports, certificates, and a self-introduction. Can the book replace them?

No. A personal learning portfolio for secondary, direct subsidy, or DSS still commonly asks for school reports, certificates, and a self-introduction. A formal publication does not replace those three. Submit the forms, results, and proofs the school asked for, under that school’s latest guidelines. The book is an extra piece at the front: something that can be opened, and something the child can talk through in the interview. It is not a grade, not a reference letter, and not an offer of a place.

Where a publication sits in a secondary portfolio is covered on another page: https://kidsmybook.com/blog/secondary-dss-interview-published-book . ## How do you place one published book in a Clear Book?

Put it at the front. Submit one A4 page. Do not photocopy the whole book into the Clear Book. That page names four things: the book title, what the child did, the ISBN, and an optional line on the physical bookstore listing path. The rest of the file stays for school reports, certificates, and the self-introduction. The hub: https://kidsmybook.com/admissions-portfolio . If the school allows only two to five A4 pages, the page limit is here: https://kidsmybook.com/blog/thin-a4-portfolio-published-book .

That one page can say the following, still inside the school’s latest form:

- The book title
- What the child did: where the interest came from, the child’s part, and which page they changed
- The ISBN, which identifies this version
- An optional line: formally printed, with a physical bookstore listing path for this title and package; the store decides stock, display, and returns

Do not put a branch guarantee, an offer of a place, or a price on that page. The only named public case is Hilary, who was eight and spent about a year on a butterfly guide. That is a publishing timeline, not an interview result at any secondary school: https://kidsmybook.com/case-studies/hilary-butterfly-guide .

## Are bringing the physical book on interview day and photocopying the whole book into the Clear Book the same thing?

No. A photocopy in the Clear Book is what the interviewer sees, and it usually breaks the space the school allowed. Bringing the physical book means that, on the day, there is a publication someone can open, and the child points to one page and talks about their own part on that page. Do not read from the cover to the last page. If the day does not allow the book, say that same page aloud. Do not add a file the school did not ask for.

## How is a pile of certificates, or an exercise book, different from one formal publication?

A pile of certificates shows classes attended and grades taken. An exercise book and a tutoring essay show practice. A formal publication is one finished piece, with an ISBN, that someone can open and talk through, and then a physical bookstore listing path for that title and package. The three can sit together. The book does not make the certificates disappear, and the certificates do not mean a book has already been published. If an interviewer reads from the first certificate to the last, the first minute rarely shows one finished interest. The page at the front gives them one publication they can check, and a place to stop. ## If timing is tight, should a family rush a weak book?

No. If the secondary interview is only days or weeks away, the about-12-month plan will not finish for this round, and a physical listing path will not appear in those days either. This page will not ask a family to rush a print run now, and it will not ask them to assemble an exercise book or a layout template and call it a formal publication. When time is short, wait for the next admissions cycle that still has about a year. That is a better file than a rushed book the child cannot explain. A start near the beginning of Primary 4 is the closer fit for a typical late-Primary 5 and Primary 6 first-term stretch. A Primary 5 start is a rush.
